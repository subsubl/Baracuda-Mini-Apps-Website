## 2025-05-22 - Static Image Optimization
**Learning:** Large static assets (like background patterns) served as standard PNGs via `<img>` tags contribute significantly to payload size and are not automatically optimized by Nuxt Image. Additionally, using `v-if` with `$colorMode` for theme-specific images below the fold causes hydration mismatches and delays LCP if not handled carefully, whereas CSS visibility toggling (`hidden dark:block`) combined with `loading="lazy"` provides a better balance of performance (no double download) and UX (no layout shift).
**Action:** Always use `<NuxtImg>` for static assets to leverage WebP conversion. For theme-switched images, prefer CSS classes over JS conditionals to avoid hydration issues, and ensure `loading="lazy"` is used for below-the-fold content to prevent downloading hidden assets.
